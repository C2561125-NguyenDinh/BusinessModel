# Data dictionary rút gọn
- `date`: ngày quan sát.
- `store_nbr`: mã cửa hàng.
- `family`: nhóm hàng, không phải SKU.
- `sales`: lượng bán quan sát, dùng làm proxy cho nhu cầu; không phải doanh thu tiền.
- `onpromotion`: số mặt hàng trong family đang được promotion; không phải % giảm giá.
- File phụ được dùng khi có; thiếu file phụ không được bịa dữ liệu.
